# Hero Siege Item Editor 2.15.0

Needs ForgePact 1.3.9 for the forged items to show up in the game.

## What's new

- **Item Forge, rebuilt.** One page, three steps: choose an item, customize it, save.
  Start from the item catalog, from an item you already own, or from a ready-made item.
- **Ready-made items.** Headhunter (belt) and Tyrant's Crown (helmet). Pick one, press
  Forge, and it lands in your Shared Stash with everything set up.
- **Give your item a name, a golden special line, a description and a rarity color.**
  They show in the game just like on a real unique.
- **Your item's own stats are listed too.** Open an item you own and its existing stats
  appear as rows you can change or remove. Once the item has been loaded in the game
  with ForgePact, the numbers are exactly what the game has.
- **Every property has a short explanation in plain words.** Open *About this property*
  under any row.
- *All Skills: Class* now always comes with *to All Skills*, so you can no longer add a
  class tag that does nothing.

## Fixed

- The **GAME RUNNING** badge no longer stays stuck on Turkish, German and other
  non-English Windows when the game is closed.
- Item Forge opens right away instead of after a two-second pause.
- Choosing an equipped item, a potion or a personal-stash item for the forge no longer
  says "item not found".
- A simpler sidebar: Save Health Check, Recovery Vault and the Simple/Advanced switch
  are gone. Everything is always available.

## How to update

Download the exe and run it. No install. Close the game before saving, as before.

# Hero Siege Item Editor 2.15.1

A quick fix for 2.15.0.

## Fixed

- **The character list was invisible.** The characters loaded, but a style rule added in
  2.15.0 to hide two old sidebar entries also hid the character buttons. They are back.
- The character list now retries if the first request is slow and refreshes itself
  every few seconds, so it can no longer stay empty after a hiccup.

Everything else is as in 2.15.0. Download the exe and run it; no install.

# Hero Siege Item Editor 2.15.4

Pairs with ForgePact 1.3.10 or newer.

## What's new

- **No more false "different Windows user" warning.** If you installed the ForgePact
  plugin, started the game once, and only then forged your first item, the Custom
  Forge screen showed a red warning claiming the game runs under another Windows
  user. It was reading an old report from that first start. The editor now compares
  the dates: an old report simply means "restart Hero Siege", and that is what it
  says. The red warning is kept for the real case, when the game started after the
  forge and still could not find it.
- If you have not forged anything yet, the screen now says so instead of warning.

Everything else is as in 2.15.3. Download the exe and run it; no install.
